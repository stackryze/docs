Release updates across **Stackryze Domains** (`domain.stackryze.com`) and **Stackryze DNS** (`dns.stackryze.com`).

## Platform milestones

<Tabs>
  <Tab title="Domains" icon="tags">
    ### Highlights

    - **Five public extensions** — `.indevs.in`, `.sryze.cc`, `.ryzedns.org`, `.nx.kg`, and `.ryzn.pro` live with 1 slot per extension by default.
    - **Centralized Stackryze SSO** — unified OpenID Connect authentication via `auth.stackryze.com` with back-channel logout and session validation.
    - **Automated GitHub Star KYC** — streamlined verification across all five extensions requiring a 30-day GitHub account and repository star.
    - **DNS ownership verification handshake** — seamless pairing between `domain.stackryze.com` and `dns.stackryze.com` via one-time `sryze-verify-...` codes.
    - **WHOIS Privacy & Lifecycle automation** — public WHOIS with registrant email redaction toggle, 60-day renewal window, 15-day grace period, and 7-day cooling-off cleanup.
  </Tab>
  <Tab title="StackNS" icon="globe">
    ### Highlights

    - **Three global authoritative servers** — `ns1.stackryze.com` (New York), `ns2.stackryze.com` (Frankfurt), and `ns3.stackryze.com` (Hyderabad) powered by PowerDNS Master/Slave replication.
    - **API Tokens & Webhooks** — scoped `sk_dns_...` Bearer tokens (`read` / `write`) and HMAC-signed webhooks (`X-Stackryze-Signature`).
    - **Control-plane automation** — batch record mutations (up to 200 per call), zone cloning, record annotations, temporary auto-expiring records (1 min–7 days), and scheduled changes.
    - **ECDSA P-256 DNSSEC & Edge Telemetry** — one-click `ECDSAP256SHA256` CSK signing, revertible audit log entries, BIND zone export, and `/api/edge/metrics` ingestion.
  </Tab>
  <Tab title="Hosting" icon="server">
    ### Planned

    - **Stackryze Hosting** is planned (`AGENTS.md` / `docs/hosting`) and not yet generally available.
  </Tab>
</Tabs>
