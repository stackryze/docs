Stackryze Domains relies on centralized authentication, GitHub verification, automated anti-abuse screening, and WHOIS redaction to keep public extensions safe for legitimate builders.

## Account security

### Stackryze SSO authentication

Authentication is centralized through [auth.stackryze.com](https://auth.stackryze.com) using OpenID Connect (ZITADEL). Passwords, Passkeys, and Multi-Factor Authentication (2FA) are managed directly in your Stackryze SSO profile rather than stored separately inside the domain dashboard.

- When a session is revoked or signed out in Stackryze SSO, back-channel logout and session validation revoke dashboard access automatically.
- Accounts signed in via GitHub with a `@users.noreply.github.com` placeholder address must add and verify a deliverable email address before registering or managing domains.

### Anti-abuse registration protections

Every new domain registration passes multiple automated checks:

- **GitHub Star KYC** — requires an account at least **30 days old** (1 GitHub account per Stackryze account) with a star on `stackryze/FreeDomains`.
- **Cloudflare Turnstile** — verifies human interaction on registration forms.
- **Network / VPN screening** — blocks high-risk automated registration traffic.
- **Rate limits** — limits availability checks to **20/minute**, domain creation to **2/hour** per IP, and GitHub verification attempts to **3 per 30 minutes**.

## WHOIS privacy and public lookups

Public WHOIS records can be queried at [domain.stackryze.com/whois](https://domain.stackryze.com/whois) (`GET /subdomains/whois?query=name.extension`).

- **Registrant Name**, **Address**, and **Phone** are **always redacted** (`REDACTED FOR PRIVACY`).
- **Registrant Email** is **hidden by default** (`whoisPrivacy: true`). You can toggle email visibility on or off under **Settings → WHOIS Privacy**.
- Public records display registration/expiry dates, current `NS` delegation, and ICANN-style EPP status (`ok`, `clientHold` for expired/suspended domains, `pendingDelete`, or `pendingUpdate`).

## Reporting abuse

Send abuse reports to [reportabuse@stackryze.com](mailto:reportabuse@stackryze.com) with:

- The exact subdomain (for example `example.indevs.in` or `example.sryze.cc`)
- The type of abuse (phishing, malware distribution, spam, C2 infrastructure)
- Reproducible URLs, headers, or UTC timestamps

### Official contact emails

Stackryze never contacts users from any domain outside `@stackryze.com`:

| Address | Purpose |
| --- | --- |
| `support@stackryze.com` | Account support, appeals, and limit increase requests |
| `reportabuse@stackryze.com` | Abuse, phishing, and Acceptable Use Policy reports |
| `security@stackryze.com` | Security vulnerability reports |
| `no-reply@stackryze.com` | Automated system notifications |

Violations of the [Terms of Service](https://domain.stackryze.com/terms) or [Acceptable Use Policy](https://domain.stackryze.com/aup) can result in domain suspension (`Suspended` status removes DNS resolution) or account bans. To appeal a suspension or ban, write to `support@stackryze.com` from your registered email address.
