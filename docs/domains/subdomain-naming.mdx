Every registration and availability check (`GET /subdomains/check/:name`) enforces the same naming validation across all five extensions.

## Format

A Stackryze Domain consists of one subdomain label under one of the five supported root zones:

```text
<label>.indevs.in
<label>.sryze.cc
<label>.ryzedns.org
<label>.nx.kg
<label>.ryzn.pro
```

Your chosen label and extension are fixed once registered.

## Length bounds

| Bound | Value |
| --- | --- |
| Minimum | 3 characters |
| Maximum | 63 characters |

## Allowed characters and Punycode policy

Labels may contain only:

- Lowercase ASCII letters (`a`–`z`)
- Digits (`0`–`9`)
- Hyphens (`-`)

The validator rejects:

- Uppercase characters (inputs are normalized to lowercase in the UI; uppercase is rejected at the API check if invalid)
- Spaces, underscores (`_`), dots (`.`), or punctuation
- Non-ASCII / Internationalized Domain Names (IDNs)
- **Punycode prefixes** starting with `xn--`

Hyphens cannot appear at the start (`-myproject`) or end (`myproject-`) of a label.

| Label | Valid | Reason |
| --- | --- | --- |
| `myproject` | Yes | Lowercase ASCII |
| `john-portfolio` | Yes | Internal hyphen allowed |
| `api2026` | Yes | Lowercase letters and digits |
| `xn--example` | No | Punycode prefixes are blocked |
| `-myproject` | No | Starts with a hyphen |
| `myproject-` | No | Ends with a hyphen |
| `my_app` | No | Underscores are not allowed |
| `ab` | No | Fewer than 3 characters |

## Reserved names and profanity filtering

Stackryze filters all candidate names through:

1. **Reserved system labels** (via `reserved-subdomains` — such as `www`, `mail`, `admin`, `api`, `dashboard`, `ns1`–`ns4`).
2. **Public safety, government, and major brand lists** — protected terms (such as emergency services, government departments, and well-known brand trademarks) cannot be registered to prevent impersonation.
3. **Automated profanity checks** — whole-word and substring profanity checks block abusive labels.

## Uniqueness and 7-day cooling-off

- Only one active account can hold a given `<label>.<extension>` combination at a time.
- If another user has a **pending manual verification reservation** for that label, availability checks return it as unavailable.
- Once a domain is **soft-deleted** (after admin approval of a deletion request or after exceeding the 15-day post-expiry grace period), the name enters a **7-day cooling-off period** before anyone can register it again.
