Whether you are keeping a home server hostname pointed to a changing public IP, issuing short-lived verification records for CI/CD, or timing a maintenance cutover, Stackryze DNS supports full programmatic control using scoped Bearer API tokens (`sk_dns_...`).

## Choosing the right automation tool

| Use case | Feature / endpoint | Behavior |
| --- | --- | --- |
| Changing public IP (home lab / VPS) | `POST` + `DELETE` `/api/zones/:id/records` | Updates `A` or `AAAA` records via Bearer `write` token. |
| Short-lived verification (`_acme-challenge`, staging) | `POST /api/zones/:id/records/temporary` | Automatically removed from PowerDNS after `1`–`10080` minutes (up to 7 days). |
| Planned cutover / timed cleanup | `POST /api/zones/:id/schedule` | Applies a `create` or `delete` operation automatically at a future UTC timestamp. |
| Multi-record template sync | `POST /api/zones/:id/records/batch` | Applies up to 200 creates/deletes in a single API call. |

## Prerequisites

1. Sign in at [dns.stackryze.com](https://dns.stackryze.com) and create a Bearer token (`POST /api/tokens`) with the **`write`** scope.
2. Copy your token immediately (tokens carry the prefix `sk_dns_` and are only displayed once).
3. Copy your Zone ID from the dashboard or `GET /api/zones`.

<Note>
  DNS records require a minimum TTL of `3600` seconds (1 hour) and maximum `604800` seconds (1 week). Mutations are rate-limited to **20 requests per minute**.
</Note>

## Updating a dynamic IP address

Because `A` records are multi-value in PowerDNS, delete the previous `A` record for the label (or pass `content` to remove a specific IP) and write the new IP:

<CodeGroup>
```bash Dynamic IP Updater (Shell)
#!/usr/bin/env bash
set -euo pipefail

API_BASE="https://api-dns.stackryze.com"
TOKEN="$STACKRYZE_DNS_TOKEN"
ZONE_ID="your-zone-id"
RECORD_NAME="home"
NEW_IP="$(curl -fsS https://api.ipify.org)"

# Remove previous A record at this label (ignore 404 on first run)
curl -fsS -X DELETE "${API_BASE}/api/zones/${ZONE_ID}/records" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"type\":\"A\",\"name\":\"${RECORD_NAME}\"}" || true

# Write current IP with minimum allowed TTL (3600s)
curl -fsS -X POST "${API_BASE}/api/zones/${ZONE_ID}/records" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"type\":\"A\",\"name\":\"${RECORD_NAME}\",\"content\":\"${NEW_IP}\",\"ttl\":3600}"
```
</CodeGroup>

## Temporary (auto-expiring) records

Use temporary records for one-off validation tokens or ephemeral test hosts. The control-plane scheduler checks every minute and removes expired records from PowerDNS automatically:

```bash
curl -X POST "https://api-dns.stackryze.com/api/zones/${ZONE_ID}/records/temporary" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "TXT",
    "name": "_acme-challenge",
    "content": "\"challenge-token-value\"",
    "ttl": 3600,
    "expiresInMinutes": 60
  }'
```

`expiresInMinutes` accepts any integer between `1` and `10080` (7 days).

## Scheduled changes

Schedule a future `create` or `delete` operation at any valid ISO-8601 UTC timestamp:

```bash
curl -X POST "https://api-dns.stackryze.com/api/zones/${ZONE_ID}/schedule" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "op": "create",
    "record": {
      "name": "maintenance",
      "type": "A",
      "content": "203.0.113.50",
      "ttl": 3600
    },
    "runAt": "2026-12-01T02:00:00Z"
  }'
```

Cancel any `pending` scheduled change before execution with `DELETE /api/zones/:id/schedule/:sid`.
