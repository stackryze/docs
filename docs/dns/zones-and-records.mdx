Stackryze DNS stores zone metadata in MongoDB and provisions authoritative zone data directly on PowerDNS Master/Slave servers.

## Zone lifecycle and states

Every zone in Stackryze DNS holds one of five statuses:

| Status | Meaning |
| --- | --- |
| `pending_ownership` | Assigned automatically when you add a platform subdomain (`.indevs.in`, `.sryze.cc`, `.ryzedns.org`, `.nx.kg`, `.ryzn.pro`). Waiting for you to confirm the `sryze-verify-...` code from [domain.stackryze.com](https://domain.stackryze.com). |
| `pending_verification` | Zone exists in PowerDNS, waiting for an uncached public resolver check confirming `NS` delegation points to `ns1–ns3.stackryze.com`. |
| `active` | Verified and actively serving queries on Stackryze nameservers. Checked daily at `03:00` with a 7-day grace period if delegation temporarily breaks. |
| `pending` | Zone record queued or not yet provisioned in PowerDNS. |
| `suspended` | Temporarily suspended; existing records are backed up in `suspended_records`. |

Protected root zones (`sryze.cc`, `indevs.in`, `ryzedns.org`, `nx.kg`, `ryzn.pro`, and `stackryze.com`) cannot be created or deleted by user accounts.

## Zone capacity & quotas

- **Default zones per account:** **3 zones** (configurable per user by administrators).
- **Default records per zone:** **200 records** (configurable per zone up to the system hard cap of **1,000 records**).
- **SOA management:** Stackryze automatically sets and auto-heals malformed SOA records to `ns1.stackryze.com. hostmaster.stackryze.com.` using `YYYYMMDD01` serials.

## Control-plane features

Beyond standard record creation and deletion, each zone supports:

- **Batch updates (`POST /api/zones/:id/records/batch`):** Create and/or delete up to **200 records** in a single call (powers zone templates, imports, and bulk deletes).
- **Zone cloning (`POST /api/zones/:id/clone`):** Copy all non-SOA/NS records from one owned zone to another owned target zone.
- **Record annotations (`GET` / `PUT /api/zones/:id/record-meta`):** Attach notes (up to 280 characters) and up to 10 searchable labels per record without modifying PowerDNS data.
- **Temporary records (`POST /api/zones/:id/records/temporary`):** Create records that automatically expire and delete from PowerDNS after **1 minute to 10,080 minutes (7 days)** — swept every minute by the scheduler.
- **Scheduled changes (`POST /api/zones/:id/schedule`):** Schedule a record `create` or `delete` for a future timestamp; applied automatically on a 1-minute scheduler loop.
- **Revertible audit log (`POST /api/audit/:id/revert`):** Track every `record.create`, `record.delete`, and `records.batch` action and roll it back in one click.
- **BIND export (`GET /api/zones/:id/export`):** Download the complete zone in standard BIND zone-file format (`$ORIGIN`, `$TTL 3600`).
