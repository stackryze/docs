Stackryze DNS validates every record before patching PowerDNS to prevent conflicting `CNAME` chains, duplicate entries, and invalid target syntax.

## User-managed record types

You can create, batch-import, schedule, or set temporary expiry on the following seven record types:

| Type | Format & validation rules | Example content |
| --- | --- | --- |
| `A` | Valid IPv4 address (`0–255` per octet) | `192.0.2.1` |
| `AAAA` | Valid full or abbreviated IPv6 address | `2001:db8::1` |
| `CNAME` | Valid DNS hostname (cannot be an IPv4 address); automatically trailing-dot normalized in PowerDNS | `target.example.com` |
| `MX` | `<priority> <hostname>` where priority is `0–65535`; duplicate target hostnames at the same record name are rejected | `10 mail.example.com` |
| `TXT` | Non-empty string up to `4096` characters | `"v=spf1 include:_spf.example.com ~all"` |
| `SRV` | `<priority> <weight> <port> <target>` (4 space-separated fields) | `0 5 5060 sip.example.com` |
| `CAA` | `<flags> <tag> <value>` (at least 3 space-separated fields) | `0 issue "letsencrypt.org"` |

<Note>
  `SOA` and `NS` records are protected and cannot be created, edited, or deleted manually through user DNS record endpoints.
</Note>

## Record name and conflict rules

- **Apex notation:** Use `@` to target the zone apex (`example.com.`).
- **Labels:** Record names allow `A–Z`, `a–z`, `0–9`, `-`, and `_` (up to 253 characters total).
- **CNAME exclusivity:** A `CNAME` record cannot coexist with any other record type (`A`, `AAAA`, `MX`, `TXT`, etc.) at the exact same record name.
- **Duplicate protection:** Exact duplicate `(name, type, content)` records are rejected.
- **Multi-value records:** Adding a new value for `A`, `AAAA`, `MX`, `TXT`, `SRV`, or `CAA` preserves existing values on that RRset; `CNAME` replaces any existing `CNAME` at that name.

## TTL bounds

All records created or scheduled in Stackryze DNS enforce:

- **Minimum TTL:** `3600` seconds (1 hour)
- **Maximum TTL:** `604800` seconds (1 week)

Requests with TTL values below `3600` or above `604800` return `400 Bad Request`.

## Built-in DNS Checker types

In addition to hosted zone management, the **DNS Checker** diagnostic tool (`GET /api/dns-checker/check/:domain/:recordType`) supports querying external domains across multiple resolvers for `A`, `AAAA`, `CNAME`, `MX`, `TXT`, `NS`, `SOA`, `PTR`, `SRV`, `CAA`, and `NAPTR`.
