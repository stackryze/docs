Stackryze DNS exposes an HTTPS JSON REST API for managing zones, DNS records, DNSSEC, scheduled changes, temporary records, and Edge monitoring telemetry.

## Base URL

```text
https://api-dns.stackryze.com/api
```

## Authentication

All Bearer-token requests use an API token generated from the [Stackryze DNS dashboard](https://dns.stackryze.com) (`Settings → API Tokens`).

```bash
curl https://api-dns.stackryze.com/api/zones \
  -H "Authorization: Bearer sk_dns_..."
```

### Token format and scopes

- **Prefix:** `sk_dns_` (the raw token is displayed once on creation; only a SHA-256 hash is stored server-side).
- **Account limit:** Up to **10 API tokens** per user account.
- **Scopes:**
  - `read` — allows `GET` / `HEAD` requests on `/api/zones*` and `/api/edge*`
  - `write` — required alongside `read` for `POST`, `PUT`, `PATCH`, and `DELETE` requests

<Note>
  Token creation, webhooks, and audit-log endpoints (`/api/tokens`, `/api/webhooks`, `/api/audit`) require an authenticated Stackryze SSO browser session rather than a Bearer token.
</Note>

## Zones

### List zones

```text
GET /api/zones
```

Returns `{ zones, limits }` containing all owned zones and account quota usage (`zoneLimit`, `currentZones`, `remainingZones`).

### Create zone

```text
POST /api/zones
```

<ParamField body="name" type="string" required>
  Apex domain or subdomain name (for example `example.com` or `myproject.indevs.in`). Trailing dots are stripped automatically. Protected platform roots (`indevs.in`, `sryze.cc`, `ryzedns.org`, `nx.kg`, `ryzn.pro`, `stackryze.com`) cannot be created.
</ParamField>

Platform subdomains start in `pending_ownership` with a generated `ownershipCode` (`sryze-verify-...`); external domains start in `pending_verification`.

<CodeGroup>
```bash cURL
curl -X POST https://api-dns.stackryze.com/api/zones \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "example.com"}'
```

```javascript JavaScript
const res = await fetch("https://api-dns.stackryze.com/api/zones", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.STACKRYZE_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "example.com" }),
});
const zone = await res.json();
```

```python Python
import os, requests

res = requests.post(
    "https://api-dns.stackryze.com/api/zones",
    headers={"Authorization": f"Bearer {os.environ['STACKRYZE_TOKEN']}"},
    json={"name": "example.com"},
)
zone = res.json()
```
</CodeGroup>

### Get, verify, export, or delete a zone

```text
GET    /api/zones/:id                     # Zone object + rrsets (?rrsets=false omits rrsets)
DELETE /api/zones/:id                     # Delete zone from PowerDNS and database
POST   /api/zones/:id/verify              # Uncached NS verification against ns1-ns3.stackryze.com
POST   /api/zones/:id/verify-ownership    # Verify Stackryze subdomain ownership code
POST   /api/zones/:id/clone               # Copy non-SOA/NS records to { "targetId": "..." }
GET    /api/zones/:id/export              # Download BIND zone file (text/plain)
```

## DNS records

### List or search records

```text
GET /api/zones/:id/records?q=&max=100
```

Returns the zone's RRsets from PowerDNS, optionally filtered by `q` (record name or content) and capped by `max` (default `100`).

### Add a record

```text
POST /api/zones/:id/records
```

<ParamField body="type" type="string" required>
  One of `A`, `AAAA`, `CNAME`, `MX`, `TXT`, `SRV`, or `CAA`. (`SOA` and `NS` cannot be edited manually.)
</ParamField>

<ParamField body="name" type="string" required>
  Relative record label (for example `www`, `@`, `_acme-challenge`).
</ParamField>

<ParamField body="content" type="string" required>
  Record value matching the type rules (for `MX`: `"10 mail.example.com"`; for `SRV`: `"0 5 5060 sip.example.com"`; for `CAA`: `"0 issue \"letsencrypt.org\""`).
</ParamField>

<ParamField body="ttl" type="number" required>
  Time to live in seconds between `3600` (1 hour) and `604800` (1 week).
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST "https://api-dns.stackryze.com/api/zones/${ZONE_ID}/records" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type":"A","name":"www","content":"192.0.2.10","ttl":3600}'
```

```javascript JavaScript
await fetch(`https://api-dns.stackryze.com/api/zones/${zoneId}/records`, {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${token}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    type: "A",
    name: "www",
    content: "192.0.2.10",
    ttl: 3600,
  }),
});
```

```python Python
requests.post(
    f"https://api-dns.stackryze.com/api/zones/{zone_id}/records",
    headers={"Authorization": f"Bearer {token}"},
    json={"type": "A", "name": "www", "content": "192.0.2.10", "ttl": 3600},
)
```
</CodeGroup>

### Delete a record

```text
DELETE /api/zones/:id/records
```

Send `{ "type": "A", "name": "www", "content": "192.0.2.10" }` in the JSON body (`content` is optional; omitting `content` deletes the matching RRset for that `name` and `type`).

### Batch create & delete

```text
POST /api/zones/:id/records/batch
```

Processes up to **200 records** combined across `create` and `delete` arrays:

```bash
curl -X POST "https://api-dns.stackryze.com/api/zones/${ZONE_ID}/records/batch" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "create": [{"type": "A", "name": "@", "content": "192.0.2.10", "ttl": 3600}],
    "delete": [{"type": "TXT", "name": "_old", "content": "\"stale\""}]
  }'
```

### Record annotations (comments & labels)

```text
GET /api/zones/:id/record-meta
PUT /api/zones/:id/record-meta
```

Attach optional comments (up to 280 chars) and up to 10 labels per `recordKey` without altering PowerDNS records.

## Temporary records & scheduled changes

```text
POST   /api/zones/:id/records/temporary   # Create expiring record (expiresInMinutes: 1..10080)
GET    /api/zones/:id/schedule            # List scheduled changes
POST   /api/zones/:id/schedule            # Schedule future { op: "create"|"delete", record, runAt }
DELETE /api/zones/:id/schedule/:sid       # Cancel a pending scheduled change
```

## DNSSEC

```text
GET    /api/zones/:id/dnssec    # Returns { secured, keys, ds, available }
POST   /api/zones/:id/dnssec    # Creates active ECDSAP256SHA256 CSK, rectifies zone, returns ds
DELETE /api/zones/:id/dnssec    # Removes all cryptokeys on the zone
```

<ResponseField name="secured" type="boolean">
  `true` when an active cryptokey is present on the zone.
</ResponseField>

<ResponseField name="ds" type="string[]">
  Formatted `DS` record strings to publish at your domain registrar.
</ResponseField>

## Edge monitoring metrics

Ingest or read aggregated health snapshots for a zone from Edge agents:

```text
POST /api/edge/metrics     # Ingest metrics (write token; requires zoneName + agentId)
GET  /api/edge/metrics     # Time-series points (?hours=24&zoneId=&region=)
GET  /api/edge/overview    # Latest snapshot per zone and region
```

## Webhooks

Manage outbound `https://` webhooks in the [Stackryze DNS dashboard](https://dns.stackryze.com) (`MAX_WEBHOOKS = 10`). Supported events:

- `record.created`
- `record.deleted`
- `zone.created`
- `zone.deleted`

Deliveries include headers `X-Stackryze-Event` and `X-Stackryze-Signature: sha256=<hmac-hex>` signed using your `whsec_...` webhook secret.

## Rate limits

| Scope | Limit |
| --- | --- |
| Global API | `100` requests / `15` minutes |
| DNS mutations (create, delete, batch, clone, DNSSEC, schedule, temporary, metadata) | `20` requests / minute |
| Authentication endpoints | `5` requests / `15` minutes |
| Ownership verification (`POST /api/zones/:id/verify-ownership`) | `5` requests / `15` minutes |
| Public NS propagation check (`GET /api/dns-checker/propagation/:domain`) | `5` requests / minute |

Exceeded limits return `429 Too Many Requests` with standard `RateLimit-*` headers.
