Stackryze DNS is an authoritative DNS hosting platform at [dns.stackryze.com](https://dns.stackryze.com) powered by PowerDNS Master/Slave replication. Use it to manage records for custom domains you own or subdomains registered through [Stackryze Domains](https://domain.stackryze.com).

<Note>
  The open-source engine is available at [github.com/stackryze/DNS](https://github.com/stackryze/DNS). Live infrastructure telemetry is available at [status.stackryze.com](https://status.stackryze.com).
</Note>

## Key specifications

| Capability | Shipped specification |
| --- | --- |
| **Authentication** | Centralized Stackryze SSO via [auth.stackryze.com](https://auth.stackryze.com), plus Bearer API tokens (`sk_dns_...`) |
| **Authoritative nameservers** | `ns1.stackryze.com` (New York), `ns2.stackryze.com` (Frankfurt), `ns3.stackryze.com` (Hyderabad) |
| **Zone model** | PowerDNS `NATIVE` zones on Master/Slave infrastructure with automatic SOA management |
| **Supported record types** | `A`, `AAAA`, `CNAME`, `MX`, `TXT`, `SRV`, `CAA` (`SOA` and `NS` managed automatically) |
| **TTL bounds** | `3600` seconds (1 hour) to `604800` seconds (1 week) |
| **Default quotas** | Up to **3 zones** per account and **200 records** per zone (configurable by admin up to 1,000) |
| **DNSSEC** | ECDSA P-256 (`ECDSAP256SHA256`) CSK signing with `DS` / `DNSKEY` inspection |
| **Automation & tooling** | Batch record changes, temporary/expiring records (1 min–7 days), scheduled record changes, zone cloning, BIND export, HMAC-signed webhooks, revertible audit log, and Edge monitoring metrics |

## Platform subdomain integration

You cannot directly hijack a `.indevs.in`, `.sryze.cc`, `.ryzedns.org`, `.nx.kg`, or `.ryzn.pro` zone in Stackryze DNS without proving ownership on Stackryze Domains. Adding any platform subdomain generates a one-time `sryze-verify-...` code that must be entered on [domain.stackryze.com](https://domain.stackryze.com) before parent `NS` delegation activates.

## What Stackryze DNS is not

- **Not a recursive resolver** — answers authoritatively for hosted zones only.
- **Not a domain registrar** — register external domains elsewhere (or claim free subdomains at [domain.stackryze.com](https://domain.stackryze.com)).
- **Not a CDN proxy** — serves authoritative DNS answers directly without proxying HTTP traffic.
