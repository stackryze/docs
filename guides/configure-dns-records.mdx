Stackryze DNS supports seven user-editable record types (`A`, `AAAA`, `CNAME`, `MX`, `TXT`, `SRV`, `CAA`) with TTL values between `3600` seconds (1 hour) and `604800` seconds (1 week).

## Supported types

<AccordionGroup>
  <Accordion title="A and AAAA" icon="globe">
    Map a hostname to an IPv4 (`A`) or IPv6 (`AAAA`) address. Multiple values on the same label are allowed.

    ```dns
    @     3600  IN  A     192.0.2.10
    api   3600  IN  AAAA  2001:db8::1
    ```
  </Accordion>
  <Accordion title="CNAME" icon="shuffle">
    Alias a hostname to another valid DNS hostname (cannot be an IPv4 address). A `CNAME` cannot coexist with any other record type on the exact same label.

    ```dns
    www   3600  IN  CNAME  example.com
    ```
  </Accordion>
  <Accordion title="MX" icon="envelope">
    Specify mail exchangers as `<priority> <hostname>` where priority is `0–65535`. Duplicate target hostnames at the same label are blocked.

    ```dns
    @     3600  IN  MX    10 mail.example.com
    ```
  </Accordion>
  <Accordion title="TXT" icon="quote-right">
    Publish verification strings, SPF, DKIM, and DMARC policies (up to `4096` characters).

    ```dns
    @       3600  IN  TXT  "v=spf1 mx -all"
    _dmarc  3600  IN  TXT  "v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"
    ```
  </Accordion>
  <Accordion title="SRV" icon="signal">
    Service locator formatted as `<priority> <weight> <port> <target>`.

    ```dns
    _minecraft._tcp  3600  IN  SRV  0 5 25565 mc.example.com
    ```
  </Accordion>
  <Accordion title="CAA" icon="lock">
    Restrict which Certificate Authorities can issue certificates formatted as `<flags> <tag> <value>`.

    ```dns
    @     3600  IN  CAA  0 issue "letsencrypt.org"
    ```
  </Accordion>
</AccordionGroup>

## Protected record types

`NS` and `SOA` records are managed automatically by Stackryze PowerDNS (`ns1.stackryze.com. hostmaster.stackryze.com.`) and cannot be created or deleted through record endpoints.

## Managing records in bulk or via API

- Use **Batch operations** in the dashboard (or `POST /api/zones/:id/records/batch`) to apply up to 200 creates and deletes at once.
- Use **Temporary records** (`POST /api/zones/:id/records/temporary`) for verification tokens that expire automatically after `1`–`10080` minutes.
- See the [DNS API reference](/docs/dns/api) for full payload schemas.
