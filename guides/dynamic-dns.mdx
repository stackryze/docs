Stackryze DNS supports automated DNS updates through the [REST API](/docs/dns/api) using scoped `sk_dns_...` Bearer tokens with `write` permission.

## Set up automated IP updates

<Steps>
  <Step title="Create a write-scoped API token">
    In [dns.stackryze.com](https://dns.stackryze.com), create an API token with **`write`** scope and store it safely (`sk_dns_...` is shown once).
  </Step>
  <Step title="Run an update script on your host">
    Use a periodic cron job or systemd timer to replace the target `A` record whenever your public IP changes:

    ```bash
    #!/usr/bin/env bash
    set -euo pipefail

    API_BASE="https://api-dns.stackryze.com/api"
    TOKEN="$STACKRYZE_DNS_TOKEN"
    ZONE_ID="your-zone-id"
    HOST="home"
    IP="$(curl -fsS https://api.ipify.org)"

    curl -fsS -X DELETE "${API_BASE}/zones/${ZONE_ID}/records" \
      -H "Authorization: Bearer ${TOKEN}" \
      -H "Content-Type: application/json" \
      -d "{\"type\":\"A\",\"name\":\"${HOST}\"}" || true

    curl -fsS -X POST "${API_BASE}/zones/${ZONE_ID}/records" \
      -H "Authorization: Bearer ${TOKEN}" \
      -H "Content-Type: application/json" \
      -d "{\"type\":\"A\",\"name\":\"${HOST}\",\"content\":\"${IP}\",\"ttl\":3600}"
    ```
  </Step>
</Steps>

<Note>
  Stackryze DNS enforces a minimum record TTL of `3600` seconds (1 hour) and a mutation rate limit of `20` requests per minute. Schedule updates every 15–60 minutes or only trigger API calls when your IP actually changes.
</Note>
