Resolve the most common errors and configuration issues on [domain.stackryze.com](https://domain.stackryze.com).

## Sign-in and GitHub verification issues

### "Account too new" during GitHub verification

**Cause:** Automated GitHub Star KYC requires a GitHub account created at least **30 days ago**.

**Fix:** Wait until your GitHub account meets the 30-day age requirement, or contact [support@stackryze.com](mailto:support@stackryze.com) with details if you need assistance.

### "GitHub account already linked"

**Cause:** Each GitHub user ID can only verify one Stackryze account (`already_linked`).

**Fix:** Sign into your existing Stackryze account through [auth.stackryze.com](https://auth.stackryze.com), or contact support from both accounts if you need help consolidating them.

### Prompted to change `@users.noreply.github.com` email

**Cause:** Stackryze Domains requires a deliverable email address for renewal notices and security alerts.

**Fix:** Enter a valid personal email on the **Update Your Email** prompt (or in **Settings**) and confirm the 6-digit verification code sent to your inbox.

### "Account banned"

**Fix:** Banned accounts violate the [Terms of Service](https://domain.stackryze.com/terms) or [Acceptable Use Policy](https://domain.stackryze.com/aup) and are signed out immediately. To appeal, email [support@stackryze.com](mailto:support@stackryze.com) from your registered email with your GitHub username.

## Registration errors

### Invalid subdomain name or Punycode error

Valid labels must:

- Be between **3 and 63 characters**
- Contain only lowercase ASCII letters (`a–z`), digits (`0–9`), and internal hyphens (`-`)
- **Not** start with `xn--` (Punycode/IDN domains are blocked), start/end with `-`, use profanity, or match reserved words/brands

### "This name is in a cooling-off period"

**Cause:** Soft-deleted domains stay locked for **7 days** before becoming available again.

**Fix:** Wait until the remaining days reported in the message expire, or register a different label.

### Captcha / VPN block errors

**Fix:** Pass the **Cloudflare Turnstile** widget before submitting, disable VPNs or aggressive content blockers that block Turnstile/API requests, and retry.

## Nameservers and resolution issues

### Nameservers accepted in dashboard, but domain fails to resolve

1. Confirm you created the zone and actual `A`, `AAAA`, or `CNAME` records inside your target DNS provider (for example Cloudflare or [dns.stackryze.com](https://dns.stackryze.com)).
2. Check parent delegation directly at Stackryze PowerDNS:

```bash
dig NS yourname.indevs.in @ns1.stackryze.com +short
```

3. If using Stackryze DNS (`dns.stackryze.com`), make sure you pasted the `sryze-verify-...` ownership code in **Domain Detail → DNS Ownership Verification** and clicked **Verify Ownership** + **Verify**.
4. Wait up to 48 hours for recursive resolver caches to refresh and clear your local DNS cache (`sudo dscacheutil -flushcache` on macOS, `ipconfig /flushdns` on Windows).

### "At least 2 nameservers are required" / format errors

Provide **2 to 6** unique, valid public DNS hostnames (such as `ava.ns.cloudflare.com`), without `http://`, IP addresses, or spaces.

## Renewal and rate limit errors

### "Renew" button disabled

- Renewals open **60 days before expiry** (or within the **15-day post-expiry grace period**).
- Domains in `Suspended` or `Pending Deletion` status cannot be renewed.

### Rate limits

| Action | Limit |
| --- | --- |
| Availability checks (`GET /subdomains/check/:name`) | `20` per minute |
| Domain creation (`POST /subdomains`) | `2` per hour per IP |
| Authentication endpoints | `15` per `15` minutes |
| GitHub KYC verification starts | `3` per `30` minutes |
| General API | `100` per `15` minutes |

Wait for the rate-limit window to reset before trying again. For unresolved issues, reach out on [Discord](https://discord.gg/wr7s97cfM7) or email [support@stackryze.com](mailto:support@stackryze.com).
