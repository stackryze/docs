Quick answers to the most common questions about [dns.stackryze.com](https://dns.stackryze.com).

## Quotas and pricing

### Is Stackryze DNS free?

Yes. Stackryze DNS is free to use after signing in through Stackryze SSO (`auth.stackryze.com`).

### What are the default quotas?

- **Zones per account:** `3` zones by default (increasable by admin upon request to [support@stackryze.com](mailto:support@stackryze.com)).
- **Records per zone:** `200` records by default (hard system cap: `1,000` records).
- **API tokens:** up to `10` tokens per account.
- **Webhooks:** up to `10` `https://` webhooks per account.

## Zones and records

### Which record types are supported?

`A`, `AAAA`, `CNAME`, `MX`, `TXT`, `SRV`, and `CAA`. `NS` and `SOA` records are managed automatically by Stackryze PowerDNS.

### What are the minimum and maximum TTL values?

All records require a TTL between **`3600` seconds (1 hour)** and **`604800` seconds (1 week)**.

### Can I export my zone?

Yes. Use the **Export BIND** option in the dashboard or call `GET /api/zones/:id/export` to download a standard BIND zone file.

## Nameservers and verification

### Which nameservers should I use?

```text
ns1.stackryze.com
ns2.stackryze.com
ns3.stackryze.com
```

### Why is my Stackryze subdomain stuck in `pending_ownership`?

Platform subdomains (`.indevs.in`, `.sryze.cc`, `.ryzedns.org`, `.nx.kg`, `.ryzn.pro`) require pasting the one-time `sryze-verify-...` code into [domain.stackryze.com](https://domain.stackryze.com) → **My Domains → DNS Ownership Verification**, then clicking **Verify Ownership** on Stackryze DNS.

## DNSSEC & API

### How does DNSSEC work?

Enabling DNSSEC creates an active **`ECDSAP256SHA256` (Algorithm 13)** CSK and returns `DS` records to add at your domain registrar.

### Where is the API base URL?

```text
https://api-dns.stackryze.com/api
```

Generate a `sk_dns_...` Bearer token from **Settings → API Tokens** with `read` or `read` + `write` scope. See the [API reference](/docs/dns/api).
